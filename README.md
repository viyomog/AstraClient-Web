## 🌌 Overview

**Astra Client Web** is the official web portal for Astra Client—a high-performance, feature-rich Minecraft launcher. Built with a focus on visual excellence and performance, this portal serves as the primary hub for downloads, feature showcases, and community support.

---

## 🚀 Client Features

*   **🤖 Astra AI Integration**: Built-in AI assistant for instant Minecraft knowledge and recipe help.
*   **🎮 Ultimate Play Interface**: A polished, distraction-free UI designed for the modern gamer.
*   **⚙️ Intuitive Settings**: Glassmorphic settings menu for precise performance and visual control.
*   **📦 Native Mod Support**: Seamless management of performance and utility mods.
*   **📰 Integrated News Feed**: Stay updated with the latest client and community news.
*   **👤 Seamless Accounts**: Effortless management of multiple Microsoft and Mojang identities.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Routing**: [React Router 7](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Vanilla CSS with modern Glassmorphism & Animations
- **Deployment**: [Vercel](https://vercel.com/)

## 💻 Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/viyomog/AstraClient-Web.git
   ```

2. Navigate to the project directory:
   ```bash
   cd AstraClient-Web
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```
